# Superseded drafts, archived 2026-08-28

Both of these were still being edited on every change and neither is going to a journal.
Keeping them cost effort on every edit and created the drift that prompted this archive:
of five additions made between 27 and 28 August, the live drafts carried all five and
these carried one.

**`manuscript-short.qmd`**, last edited 20 August. Titled "Wind does not explain mountain
pine beetle refugia", which is the conclusion the 16-day models reversed. It cites 30
works, more than any current draft, and is the only place several of them are cited; it is
kept for that reason and as the record of the numbered R1 to R15 review structure the
project abandoned.

**`beetle-topography-wind-study.qmd`**, the long version, about 15,800 rendered words. Its
Materials and Results are still written around the provincial aerial survey as the response
and the Global Wind Atlas as the wind term. Both were dropped on 2026-08-26. It also
carries the five numbers its own model table contradicts, corrected in the live drafts on
2026-08-27 but never here.

Neither should be rendered or cited. The live drafts are in `01.manuscript/`.
