# beetle-topography-and-wind-study

Terrain conditioning of mountain pine beetle disturbance, and the elevation confound in
terrain-derived wind surfaces. Darkwoods Conservation Area, British Columbia.

See [INDEX.md](INDEX.md) for the layout, the traps in the data, and the open items.
The manuscript is `01.manuscript/beetle-topography-wind-study.qmd` and is fully executable:
rendering it runs the analysis.
