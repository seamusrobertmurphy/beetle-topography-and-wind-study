# archive

**Empty, and deliberately so.** This folder holds nothing but a `.gitkeep`.

It exists as the destination for input datasets that have been superseded but are worth
keeping out of the working folders rather than deleting outright. Nothing in the manuscript
reads it, and nothing should be added to it that the manuscript does read.

If you move something here, add a line to this file recording what it was, where it came
from, and what replaced it. An archive without that record is just clutter.
